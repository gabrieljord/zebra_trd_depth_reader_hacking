### Device pogo pin pinout

Pin 1: GND (Power/signal ground)

Pin 2: RXD_MIC (UART RXD + Headset microphone)

Pin 3: PWR_IN_CON (External 5.4 VDC power input)

Pin 4: TRIG_PTT (Trigger or PTT input)

Pin 5: GND (Power/signal ground)

Pin 6: USB-OTG_ID (USB OTG ID pin)

Pin 7: TXD_EAR (UART TXD, Headset ear)

Pin 8: USB_OTG_VBUS (USB VBUS)

Pin 9: USB_OTG_DP (USB DP)

Pin 10: USB_OTG_DM (USB DM)
